# Practix - 기능 명세서

## 앱 개요
음악 연습을 위한 A/B 비교 앱. 원곡과 녹음을 비교하며 효율적으로 연습할 수 있음.

---

## 1. 데이터 구조

### 계층 구조
```
Song (곡)
└── Session (연습 세션)
    ├── audioData (원곡 오디오)
    ├── markers (시간 마커)         
    └── Section (구간)
        ├── start/end (시작/끝 시간)
        ├── memo (메모)
        ├── backingTrack (반주)
        └── Recording[] (녹음 목록)
            ├── data (오디오 데이터)
            └── tags (태그)
```

### 저장소
- **웹**: localStorage (메타데이터) + IndexedDB (오디오)
- **모바일**: Capacitor Filesystem
- **클라우드**: Supabase (선택적 동기화)

## 2. 핵심 기능

### 2.1 곡/세션 관리
| 기능 | 설명 |
|------|------|
| 곡 추가 | 새 곡 생성 |
| 곡 삭제 | 곡과 관련 세션 모두 삭제 |
| 세션 추가 | 곡 내 새 연습 세션 생성 |
| 세션 삭제 | 세션과 관련 오디오/구간 삭제 |
| 원곡 불러오기 | 오디오 파일 업로드 및 파형 표시 |

### 2.2 파형 시각화
| 기능 | 설명 |
|------|------|
| 파형 렌더링 | 오디오 버퍼를 캔버스에 시각화 |
| 줌 레벨 | 전체, 1분, 30초, 10초 |
| 스크롤 | 줌 상태에서 좌우 스크롤 |
| 현재 위치 표시 | 재생 중 빨간 선으로 표시 |
| 구간 표시 | 생성된 구간을 색상으로 표시 |

### 2.3 구간 관리
| 기능 | 설명 |
|------|------|
| 구간 생성 | 파형에서 드래그로 시작/끝 지정 |
| 자동 스크롤 | 드래그 시 가장자리에서 자동 스크롤 |
| 구간 삭제 | 개별 구간 삭제 |
| 구간 접기/펼치기 | 카드 UI로 컴팩트하게 표시 |
| 구간 메모 | 각 구간에 메모 추가 |

### 2.4 재생 기능
| 기능 | 설명 |
|------|------|
| 전체 재생 | 원곡 전체 재생/일시정지 |

| 루프 재생 | 구간 반복 재생 |

- **오디오**: Web Audio API

## 4. 플랫폼별 차이

| 기능 | 웹 | 모바일 |
|------|-----|--------|
| 저장소 | IndexedDB | Filesystem |
| UI 헤더 | 일반 | 네이티브 스타일 |
| Safe Area | 불필요 | 적용 |
| 파일 선택 | input[type=file] | 동일 |

---

## 5. 데이터 영속성

### 오디오 마커 시스템
- `'idb'`: IndexedDB에 저장됨 (웹)
- `'file'`: 파일시스템에 저장됨 (모바일)
- `'data:...'`: base64 데이터 (임시)

### 저장 흐름
1. 오디오 파일 선택
2. base64로 인코딩
3. 플랫폼에 따라 저장 (IDB/Filesystem)
4. 메타데이터에 마커만 저장

## 6. 알려진 제한사항

- 오프라인 모드: 클라우드 없이 로컬만 사용 가능
- 파일 크기: 대용량 오디오는 성능 영향
- 브라우저 호환: Web Audio API 필요
