# Practix - 제품 현황 문서 (기획/디자인용)

> 최종 업데이트: 2026-04-08 | 버전: 0.1.1 (프리릴리즈)

---

## 1. 제품 소개

**Practix**는 음악 연습용 A/B 비교 앱입니다.

원곡에서 연습할 구간을 지정하고, 본인 연주를 녹음한 뒤 원본과 나란히 비교 청취할 수 있습니다.
메트로놈, 반주(MR), 악보, 피치 분석, 튜너 등 연습에 필요한 도구를 함께 제공합니다.

- **타겟 유저**: 악기/보컬 연습자 (독학, 레슨, 합주 준비 등)
- **플랫폼**: Android + iOS + 웹 (모바일 우선 디자인)
- **데이터 저장**: 로컬 전용 (기기 내 저장)

### 3-4. 연습 페이지 (핵심 화면)

```
┌─────────────────────────────┐
│  [←뒤로]  1차 연습     [⋮]  │  ← 세션 이름 + 더보기 메뉴
│           나의 노래          │     (곡 이름 서브타이틀)
├─────────────────────────────┤
│  ┌───────────────────────┐  │
│  │  [📁 원곡 업로드됨] 3:24│  ← 오디오 업로드 상태
│  │  ▓▓▓░░▓▓▓▓░░▓▓░░▓▓▓▓ │  ← 파형 디스플레이
│  │       ▼ (재생헤드)      │
│  │  [줌: 전체|60s|30s|10s] │  ← 줌 컨트롤 (우상단)
│  │                         │
│  │  0:42 / 3:24            │  ← 시간 표시
│  │  ──●─────────────────  │  ← 스크롤 슬라이더 (줌 시)
│  │                         │
│  │  [⏮] [▶재생] [⏭]      │  ← 재생 컨트롤
│  │  [0.5x|1x|1.5x|2x]    │  ← 재생 속도
│  │  [🔁루프]               │
│  └───────────────────────┘  │
│                             │
│  ┌───── 메트로놈 ─────────┐ │
│  │ BPM: 120  박자: 4/4    │ │  ← 글로벌 메트로놈
│  │ [▶ 시작] [볼륨 ──●──]  │ │
│  └───────────────────────┘  │
│                             │
│  ┌───── 볼륨 믹서 ────────┐ │
│  │ 원곡    ──●──────────  │ │
│  │ MR      ────●────────  │ │  ← 독립 볼륨 슬라이더
│  │ 메트로놈 ──────●──────  │ │
│  └───────────────────────┘  │
│                             │
│  ── 구간 목록 ──────────── │
│  ┌───────────────────────┐  │
│  │ ① 인트로  0:00-0:32   │  │
│  │    🎤×3   [▶] [∨ 펼침] │  │  ← 구간 카드 (접힌 상태)
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │ ② 절 A   0:32-1:15    │  │
│  │    🎤×5   [▶] [∧ 접기] │  │  ← 구간 카드 (펼친 상태)
│  │  ─────────────────────│  │
│  │  [구간 연습 →]         │  │  ← A/B 비교 모달 열기
│  │  녹음: 녹음1, 녹음2... │  │
│  │  메모: "브릿지 주의"   │  │
│  │  [🗑️ 삭제]             │  │
│  └───────────────────────┘  │
│  [＋ 구간 추가]             │
│                             │
│                        [🔴] │  ← 기본 녹음 FAB (우하단)
│                             │
├─────────────────────────────┤
│  🎵 연습  │ 🥁 메트로놈 │ 🎤 │
└─────────────────────────────┘

[⋮ 더보기 메뉴] → 도구 런처 바텀시트:
┌─────────────────────────────┐
│  ──── (핸들 바)             │
│  🎼 악보           >       │
│  📊 피치 분석 [Beta]  >    │
│  🎤 기본 녹음        >     │
│  🔧 오디오 기기      >     │
└─────────────────────────────┘
```

#### 파형 영역

| 요소 | 인터랙션 |
|------|----------|
| 파형 | 터치 드래그 → 재생 위치 이동 |
| 파형 | 길게 드래그 → 구간 생성 |
| 줌 버튼 | 탭 → 파형 확대/축소 |
| 재생 버튼 | 탭 → 재생/일시정지 |
| 스크롤 바 | 줌 상태에서 드래그 → 파형 좌우 이동 |

#### 구간 카드

| 요소 | 인터랙션 |
|------|----------|
| 카드 헤더 | 탭 → 펼침/접기 |
| ▶ 버튼 | 탭 → 해당 구간만 재생 |
| "구간 연습" 버튼 | 탭 → A/B 비교 모달 열기 |
| 카드 전체 | 길게 누르고 드래그 → 순서 변경 |
| 신규 구간 | 초록색 테두리 + 하이라이트 애니메이션 |

#### 기본 녹음 FAB

| 상태 | 동작 |
|------|------|
| 대기 | 🔴 마이크 아이콘 |
| 탭 | 즉시 녹음 시작 (또는 카운트다운 후) |
| 길게 누르기 (0.5초) | 카운트다운 시간 선택 다이얼 표시 |
| 녹음 중 | ⬛ 정지 아이콘 + 빨간 펄스 애니메이션 |

### 3-5. 구간 연습 모달 (A/B 비교) — 핵심 연습 화면

구간 카드에서 "구간 연습"을 누르면 열리는 전체화면 모달.

```
┌─────────────────────────────┐
│  [← 뒤로]  인트로  0:00-0:32│  ← 구간 이름 (탭하여 수정)
├─────────────────────────────┤
│                             │
│  ┌─── 구간 파형 ──────────┐ │
│  │  0:15 / 0:32            │ │
│  │  ▓▓▓▓▓░░▓▓▓▓░░▓▓▓▓▓▓  │ │  ← 구간 범위 파형
│  │  [|←] [-1s][+1s] [→|]  │ │  ← 구간 경계 미세 조정
│  │                         │ │
│  │     [⏮] [▶] [🔁]       │ │  ← 재생 / 리셋 / 루프
│  └─────────────────────────┘ │
│                             │
│  ┌─── 녹음 ───────────────┐ │
│  │  [🔴 녹음] [카운트다운: 3초]│ │
│  │  레벨: ▓▓▓▓░░░░░░░░░░  │ │  ← 실시간 레벨 미터
│  └─────────────────────────┘ │
│                             │
│  ┌─── 반주/메트로놈 ──────┐ │
│  │  MR: [파일 업로드]      │ │
│  │  메트로놈: 120 BPM 4/4  │ │
│  │  [▶ 시작]               │ │
│  └─────────────────────────┘ │
│                             │
│  ┌─── 메모 ───────────────┐ │
│  │  "이 부분 리듬 주의"    │ │
│  └─────────────────────────┘ │
│                             │
│  ── 녹음 목록 ─────────── │
│  • 녹음 1  [좋음] [▶]      │
│  • 녹음 2  [다시] [▶]  ← 선택│
│  • 녹음 3  [▶]              │
│                             │
│  ┌─── A/B 비교 플레이어 ──┐ │  ← 녹음 선택 시 표시
│  │                         │ │
│  │  🎵 A/B 비교 플레이어   │ │
│  │  [🔁 루프] [1x ▼ 속도]  │ │
│  │                         │ │
│  │  밸런스: 원본 ──●── 녹음│ │  ← A/B 밸런스 슬라이더
│  │                         │ │
│  │  ┌─ 원곡 (파란색) ────┐ │ │
│  │  │ [▶] ▓▓░░▓▓▓░░ 🔊──│ │ │  ← 파형 + 볼륨
│  │  └────────────────────┘ │ │
│  │                         │ │
│  │  ┌─ 반주 (초록색) ────┐ │ │
│  │  │ [▶] MR 재생    🔊──│ │ │  ← MR/메트로놈
│  │  └────────────────────┘ │ │
│  │                         │ │
│  │  ┌─ 녹음 (빨간색) ────┐ │ │
│  │  │ [◀] 녹음2 (2/3) [▶]│ │ │  ← 녹음 전환 (스와이프)
│  │  │ [▶] ▓░░▓▓▓░░░ 🔊──│ │ │
│  │  │ • • ● (도트 내비)   │ │ │
│  │  │ [⚡싱크] [⚙️조정]    │ │ │  ← 자동 싱크 / 수동 조정
│  │  └────────────────────┘ │ │
│  │                         │ │
│  │  [원곡+녹음] [전체] [⏮] │ │  ← 재생 모드 버튼
│  └─────────────────────────┘ │
│                             │
│  [🗑️ 구간 삭제]              │  ← 맨 하단 (빨간 텍스트)
└─────────────────────────────┘
```

#### A/B 비교 플레이어 상세

| 영역 | 색상 | 인터랙션 |
|------|------|----------|
| 원곡 트랙 | 파란색 계열 | 개별 재생, 볼륨, 음소거 |
| 반주 트랙 | 초록색 계열 | 개별 재생, 볼륨 (MR 또는 메트로놈) |
| 녹음 트랙 | 빨간색 계열 | 개별 재생, 볼륨, 좌우 스와이프로 녹음 전환 |
| 밸런스 슬라이더 | — | 드래그하여 원본↔녹음 밸런스 조절 |
| 싱크 버튼 | ⚡ | 탭 → 자동으로 원본-녹음 시작점 정렬 |
| 싱크 조정 | ⚙️ | 탭 → 수동 오프셋 미세 조정 |
| 재생 모드 | — | "원곡+녹음" / "전체 재생" / "처음으로" |

#### 녹음 전환 인터랙션

| 방법 | 동작 |
|------|------|
| ◀ ▶ 버튼 | 이전/다음 녹음으로 전환 |
| 좌우 스와이프 | 녹음 카드를 스와이프하여 전환 (햅틱 피드백) |
| 도트 네비게이션 | 현재 녹음 위치 표시 (● ○ ○) |

### 3-6. 메트로놈 페이지

```
┌─────────────────────────────┐
│  [← 뒤로]    메트로놈        │
├─────────────────────────────┤
│                             │
│         ┌─────┐             │
│         │ 120 │  BPM        │  ← BPM 표시 (숫자 입력 가능)
│         └─────┘             │
│      [−5] [−1] [+1] [+5]   │  ← 증감 버튼
│                             │
│      [  탭 템포  ]          │  ← 3번 이상 탭하여 BPM 측정
│                             │
│  박자: [4/4] [3/4] [2/4]   │
│        [6/8] [2/2]         │  ← 박자 선택 (토글 버튼)
│                             │
│  강박:  ● ○ ○ ○            │  ← 강세 비트 선택
│                             │
│     ○   ○   ●   ○          │  ← 비트 인디케이터
```

## 4. 사용자 시나리오

### 시나리오 1: 첫 사용 — 곡 등록부터 첫 녹음까지

```
유저: 기타 독학 중인 대학생, 좋아하는 곡의 솔로 파트를 연습하고 싶음

1. 앱 설치 → 온보딩 튜토리얼 확인 (또는 스킵)
2. 곡 목록에서 [＋] 탭 → "Hotel California" 입력
3. 세션 목록에서 [＋] 탭 → "기타 솔로 연습" 입력
4. 연습 페이지 → 파형 영역에 원곡 mp3 업로드
5. 파형이 표시되면 솔로 구간(2:15~2:48)을 드래그하여 구간 생성
6. 생성된 구간 카드 "구간 1" 탭 → "구간 연습" 버튼
7. 구간 연습 모달에서 원곡을 0.7x 속도로 느리게 재생하며 연습
8. 준비되면 [🔴 녹음] 탭 → 3초 카운트다운 후 녹음 시작
9. 연주 끝나면 [⬛ 정지]
10. A/B 비교 플레이어에서 원본과 녹음을 나란히 재생
11. "다시" 태그 붙이고 메모: "16마디 리듬 틀림"
12. 다시 녹음 → 이번엔 "좋음" 태그
13. ◀ ▶ 버튼으로 두 녹음을 비교하며 성장 확인
```

### 시나리오 2: 반주와 함께 보컬 연습

```
유저: 보컬리스트, 공연 전 MR로 연습하고 싶음

1. 기존 곡에서 세션 추가 → "공연 리허설"
2. 원곡 업로드 후 절/후렴/브릿지 구간 3개 생성
3. "절 A" 구간 연습 모달 열기
4. 반주 섹션에서 MR 파일 업로드
5. 메트로놈 120 BPM, 4/4 설정 → MR과 싱크
6. 볼륨 믹서: 원곡 30% / MR 80% / 메트로놈 50%
7. MR 틀면서 녹음
8. A/B 비교로 원곡 보컬과 내 보컬 비교
9. 밸런스 슬라이더로 원본↔녹음 비율 조절하며 디테일 확인
```

### 시나리오 3: 레슨 피드백 활용

```
유저: 피아노 학생, 선생님이 보내준 시범 연주와 비교하고 싶음

1. 곡 추가 → 선생님 시범 연주 mp3 업로드
2. 어려운 패시지 구간 지정
3. 악보 도구 → 악보 사진 업로드 → 구간별 색상 매핑
4. 구간 연습 모달 → 느린 속도(0.5x)로 반복 재생하며 연습
5. 여러 번 녹음 → 태그로 "1차 시도", "교정 후" 등 구분
6. A/B 비교로 선생님 연주와 비교
7. 자동 싱크로 정확한 타이밍 비교
8. 통계 페이지에서 이번 주 연습량 확인
```

### 시나리오 4: 이동 중 메트로놈/튜너만 사용

```
유저: 합주 전 악기 조율 + 템포 확인만 하고 싶음

1. 앱 열기 → 하단 탭에서 🎤 튜너 선택
2. [청음 시작] → 악기 소리 내서 음정 확인
3. 하단 탭에서 🥁 메트로놈 선택
4. 합주 곡 BPM(140) 설정 → 탭 템포로 확인
5. 메트로놈 재생하며 리듬 워밍업
```

### 시나리오 5: 장기 연습 관리

```
유저: 매일 1시간 연습을 목표로 꾸준히 하고 싶음

1. 통계 페이지 → [⚙️ 목표 설정]
2. 일일 연습 시간: 60분 / 일일 녹음: 10회 / 주간: 5일
3. 매일 연습 후 통계 확인 → 목표 달성률 체크
4. 주간 차트로 연습 패턴 파악 (주말에 덜 한다 등)
5. 업적 해금으로 동기부여 (🏆 7일 연속 달성!)
6. 태그 히트맵으로 "다시" 태그가 많은 구간 집중 연습
```

## 5. 데이터 구조 (개념)

```
곡 (Song)
│
├── 세션 (Session) ─ 원곡 오디오 파일 1개
│   │
│   ├── 구간 (Section) ─ 시작~끝 시간
│   │   ├── 녹음 (Recording) ─ 여러 개 가능
│   │   │   ├── 태그 (예: "좋음", "피드백 필요")
│   │   │   ├── 메모
│   │   │   └── 싱크 오프셋 + 트림 범위
│   │   │
│   │   └── 반주 (BackingTrack) ─ MR / 메트로놈 / 커스텀
│   │
│   ├── 기본 녹음 (구간 없이 전체 녹음)
│   └── 메트로놈 설정 (BPM, 박자)
│
└── 악보 (이미지 + 구간별 영역)
```

**관계 요약**:
- 1 곡 → N 세션 (같은 곡을 여러 버전으로 연습)
- 1 세션 → N 구간 (연습할 부분 여러 개)
- 1 구간 → N 녹음 (같은 구간 반복 녹음하며 비교)

## 7. 디자인 개선 필요 영역

### 🔴 높음 (UX에 직접 영향)

| 영역 | 현재 문제 | 개선 방향 |
|------|-----------|-----------|
| **원곡 업로드 UX** | 파형 영역이 비어있을 때 업로드 유도가 약함 | 큰 CTA + 지원 포맷 안내 + 드래그앤드롭 |
| **구간 생성 방법** | 파형 드래그로 생성하는 걸 유저가 모를 수 있음 | 툴팁, 가이드 오버레이, 또는 명시적 "구간 추가" 버튼 강화 |
| **A/B 비교 정보 과밀** | 구간 연습 모달에 기능이 너무 많아 스크롤이 김 | 탭/아코디언으로 영역 분리, 또는 단계별 UI |
| **녹음 중 시각 피드백** | FAB 색상 변경 + 펄스뿐, 녹음 시간 표시 작음 | 화면 상단에 녹음 상태 바, 파형 실시간 표시 |
| **블루투스 이어폰 안내** | 녹음 시 음질 저하되는데 사전 안내 없음 | 블루투스 감지 시 "유선 이어폰 권장" 안내 표시 |

### 🟡 중간 (사용성 개선)

| 영역 | 현재 문제 | 개선 방향 |
|------|-----------|-----------|
| **곡/세션 구조 이해** | "곡 > 세션 > 구간" 3단계가 직관적이지 않을 수 있음 | 온보딩에서 개념 설명, 또는 2단계로 단순화 검토 |
| **빈 상태 디자인** | 곡/세션이 없을 때 텍스트만 표시 | 일러스트 + 액션 유도 (예: "첫 곡을 추가해보세요!") |
| **다크 모드 일관성** | 일부 모달/바텀시트에서 다크 모드 색상 불일치 | 전체 컬러 팔레트 통일 |
| **구간 카드 정보 밀도** | 접힌 상태에서 보이는 정보가 제한적 | 미니 파형 프리뷰, 최근 녹음 태그 표시 |
| **통계 시각화** | 기본적인 막대 그래프만 있음 | 더 풍부한 차트 (캘린더 히트맵, 트렌드 라인) |

### 🟢 낮음 (폴리시)

| 영역 | 현재 문제 | 개선 방향 |
|------|-----------|-----------|
| **앱 아이콘** | 기본 아이콘 | 브랜드 아이덴티티 반영한 전용 아이콘 |
