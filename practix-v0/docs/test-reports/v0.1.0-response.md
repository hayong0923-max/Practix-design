## 🔴 긴급 수정 (v0.1.1)

### 1. 카운트다운 클릭 시 파일 탐색기 열림
- **파일**: `RecordingButtons.tsx`
- **원인**: 카운트다운 다이얼 영역이 파일 input과 겹치거나 이벤트 버블링 문제
- **해결**: 이벤트 전파 차단 (`e.stopPropagation()`) 및 클릭 영역 분리

### 2. Practice Page에서 A/B 슬라이더 작동 안함
- **파일**: `ABComparePlayer.tsx`, `PracticePage.tsx`
- **원인**: Practice Page와 Modal에서 다른 props 전달 가능성
- **해결**: 두 환경에서 동일한 props 전달 확인, 이벤트 핸들러 점검

### 3. 녹음 선택 안됨
- **파일**: `RecordingsList.tsx`
- **원인**: 선택 상태 관리 또는 클릭 핸들러 문제
- **해결**: `onSelect` 핸들러 및 `selectedId` 상태 확인

### 4. 다크모드 글씨 안보임
- **파일**: 전역 CSS 또는 Tailwind 설정
- **원인**: 다크모드 텍스트 색상 미적용
- **해결**: `dark:text-white` 등 다크모드 클래스 전체 점검

### 5. Practice Page 카운트다운 녹음 안됨
- **파일**: `PracticePage.tsx`, `BottomControlBar.tsx`
- **원인**: 메인 페이지에서 카운트다운 녹음 로직 연결 안됨
- **해결**: 모달과 동일한 녹음 시작 로직 연결
