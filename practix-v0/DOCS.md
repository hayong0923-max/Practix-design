# Practix - 음악 연습 앱

## 프로젝트 개요

**Practix**는 악기 연주자와 보컬리스트를 위한 구간 반복 연습 앱입니다.
원곡의 특정 구간을 반복 재생하며 연습하고, 자신의 연습을 녹음하여 원곡과 비교할 수 있습니다.

---

## 사업 방향

### 타겟 사용자
- **1차 타겟**: 악기 독학자 (피아노, 기타, 플룻, 대금 등)
- **2차 타겟**: 보컬 트레이닝 중인 사용자
- **3차 타겟**: 음악 학원/레슨 선생님과 학생

### 핵심 문제 해결
| 기존 문제 | Practix 해결책 |
|-----------|----------------|
| 유튜브로 연습 시 구간 반복이 불편함 | 원클릭 구간 생성 + 무한 루프 |
| 내 연주가 원곡과 얼마나 다른지 모름 | A/B 비교 재생 + 피치 비교 |
| 연습 기록이 흩어져 있음 | 곡별/세션별 녹음 관리 |
| 메트로놈 앱 따로, 녹음 앱 따로 | 올인원 연습 도구 |

### 수익 모델 (예정)
1. **프리미엄 구독** - 무제한 녹음 저장, 클라우드 동기화
2. **광고** - 무료 버전 배너/전면 광고
3. **B2B** - 음악 학원용 단체 라이선스

## 핵심 기능

### 1. 구간 연습 (Section Practice)
```
[원곡 업로드] → [파형에서 구간 선택] → [구간 반복 재생]
```
- 드래그로 구간 생성
- 깃발(Flag) 마커로 시작점 찍고 끝점에서 구간 확정
- 구간별 메모 기능
- 0.25x ~ 2x 배속 조절

### 2. 녹음 & 비교 (Record & Compare)
```
[구간 선택] → [카운트다운 녹음] → [A/B 비교 재생]
```
- 즉시 녹음 / 카운트다운 녹음 (0.5초~5초 조절 가능)
- 반주(MR) 또는 메트로놈과 함께 녹음
- **A/B 비교 플레이어**: 원곡과 내 녹음을 동시 재생
- 밸런스 슬라이더로 원곡/녹음 볼륨 조절
- **싱크 편집**: 녹음 시작점을 원곡에 맞춤 (±3초)

### 3. 피치 비교 (Beta)
```
[원곡 분석] → [녹음 분석] → [피치 그래프 비교]
```
- YIN 알고리즘 기반 피치 검출
- 원곡/녹음 피치를 겹쳐서 시각화
- 일치율(%) 표시
- 단선율 악기에 최적화 (플룻, 대금, 보컬 등)

### 4. 반주 트랙 (Backing Track)
- **MR 업로드**: MP3/WAV 파일 업로드
- **메트로놈**: BPM + 박자(4/4, 3/4, 6/8 등) 설정
- 녹음 시 반주와 함께 재생

### 5. 녹음 관리
- 녹음별 이름 변경, 태그 부착
- 커스텀 태그 생성 (색상 선택)
- 휴지통 기능 (실수 삭제 방지)
- 곡 > 세션 > 구간 > 녹음 계층 구조

### 6. 악보 연동 (Sheet Music)
- 악보 이미지 업로드
- 구간과 악보 영역 연결
- 구간 재생 시 해당 악보 영역 표시

## 로드맵

### Phase 1: MVP (현재) ✅
- [x] 구간 생성 및 반복 재생
- [x] 녹음 및 A/B 비교
- [x] 메트로놈/MR 지원
- [x] 모바일 앱 (Capacitor)
- [x] 피치 비교 (Beta)
- [x] 싱크 편집

### Phase 2a: 리텐션 & 바이럴 (localStorage)
> 백엔드 없이 로컬 저장으로 구현

- [ ] **연습 로그 시스템**: 녹음과 별도로 연습 기록 저장
- [ ] **연습 스트릭**: 연속 연습 일수 표시 + 캘린더 히트맵
- [ ] **주간 리포트**: 이번 주 연습 시간, 녹음 수, 가장 많이 연습한 곡
- [ ] **성취 뱃지**: 첫 녹음, 연속 7일, 100개 녹음 등
- [ ] **연습 목표 설정**: 일일/주간 목표

```
구현 난이도: ⭐⭐ (낮음)
필요 기술: localStorage
저장소: 로컬 only (기기 변경 시 초기화)

⚠️ 핵심 설계: 연습 로그 ≠ 녹음 파일
- 녹음 삭제해도 연습 기록은 유지
- 별도의 PracticeLog 타입으로 관리
```

### Phase 2b: 선택적 로그인 (클라우드 백업)
> 통계/뱃지 클라우드 동기화

- [ ] **Supabase Auth**: Google/Apple 소셜 로그인
- [ ] **통계 클라우드 저장**: 연습 로그, 뱃지 동기화
- [ ] **기기 간 동기화**: 로그인하면 다른 기기에서도 통계 유지
- [ ] **녹음 공유 링크**: 웹 플레이어로 녹음 공유 (URL 생성)

```
구현 난이도: ⭐⭐⭐ (중간)
필요 기술: Supabase Auth, Storage (통계만)
수익 모델: 광고 (무료) / 광고 제거 (유료)

💡 비로그인 유저도 앱 사용 가능
   로그인 유도: "로그인하면 기록이 저장됩니다"
```

### Phase 3: AI 피드백 (API 연동)
> OpenAI API로 자동 피드백

- [ ] **자동 분석 리포트**: 피치/리듬 분석 결과 요약
- [ ] **GPT 피드백 생성**: 분석 데이터 → 자연어 피드백
- [ ] **피드백 톤 설정**: 격려형 / 코칭형 / 디테일형
- [ ] **구간별 코멘트**: "이 부분에서 박자가 빨라요" 등

```
구현 난이도: ⭐⭐⭐ (중간)
필요 기술: OpenAI API, 피치/리듬 분석 고도화
수익 모델: 피드백당 과금 (종량제) 또는 프리미엄 구독
```

### Phase 4: 학생-튜터 연결 (B2B)
> 본격적인 B2B 모델

- [ ] **사용자 역할 분리**: 선생님/학생 계정
- [ ] **학생 초대 시스템**: 초대 코드 또는 링크
- [ ] **연습 기록 공유**: 선생님에게 녹음 + 통계 전송
- [ ] **선생님 대시보드**: 학생별 진도, 연습량, 녹음 리스트
- [ ] **피드백 작성**: 선생님이 녹음에 코멘트 달기
- [ ] **(장기) AI 스타일 학습**: 선생님 피드백 패턴 학습 → AI 대체

```
구현 난이도: ⭐⭐⭐⭐⭐ (높음)
필요 기술: Supabase Full (Auth + DB + Storage + Realtime)
수익 모델: 선생님 월정액 구독, 학생 수 기반 과금
```

### 데이터 구조 (Phase 2용)

```typescript
// 연습 로그 - 녹음과 별도 저장
interface PracticeLog {
  date: string;           // "2024-01-15"
  songId: number;
  songName: string;
  totalDuration: number;  // 연습 시간 (초)
  recordingsMade: number; // 녹음 횟수
  sectionsCreated: number;
}

// 성취 뱃지
interface Achievement {
  id: string;             // "first_recording", "streak_7", etc.
  name: string;
  description: string;
  unlockedAt: string | null;
}

// 연습 통계 (집계)
interface PracticeStats {
  currentStreak: number;  // 현재 연속 일수
  longestStreak: number;  // 최장 연속 일수
  totalRecordings: number;
  totalPracticeTime: number;
  achievements: Achievement[];
}
```

## 핵심 가치 제안

> **"연습은 혼자, 피드백은 즉시"**

1. **효율적인 연습**: 원하는 구간만 무한 반복
2. **객관적인 피드백**: 원곡과 비교하여 부족한 점 파악
3. **체계적인 관리**: 모든 연습 기록을 한 곳에서 관리
4. **올인원 도구**: 메트로놈, 녹음, 비교를 하나의 앱에서
